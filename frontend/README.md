# CalmPulse — Anxiety Support Wearable Frontend

## Run it
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` with Live Server, or double-click it in a browser.

No installation, backend, or API key is required.

## Included screens
- Overview dashboard with illustrative HR, HRV, EDA and movement readings
- Simulated signal change / reset demo
- Active support with paced breathing and grounding UI
- Mood check-ins and demo episode history
- AI-insights concept with preset reflection text
- Trusted contacts demo and safety preferences
- Privacy & safety explainer

## Important project boundary
This is a frontend-only prototype. Readings are sample data; no real wearable, Bluetooth, database, AI API, or notifications are connected. It is a wellness-support concept, not a diagnostic medical tool.

## Suggested next integration steps
1. Connect ESP32/BLE data to a mobile or web bridge.
2. Add backend endpoints and persistent database storage.
3. Add a real, privacy-reviewed AI service for summaries/support language.
4. Implement authenticated, consent-based trusted-contact notifications.
